# 淋语翻译器 1.21.1 · 第十七轮质检（洛克淋国）

> 上一版 1.21.0 是「往里加」，这一版是「往外清」。

## 一、词库：剔除 28 条与淋语无关的纯玩法词条

词库 **1361 → 1333**（-28），`洛克淋国` 语义位 **131 → 103 条**、译法变体 **296 → 237**。

### 保留口径

满足任一条即保留：谐音空耳 / 拟人化·宫斗腔·饭圈腔 / 自称与人称体系 / 通讯录审美与圈层黑话 / 带调侃的角色外号 / 生动比喻型黑话。

### 剔除口径

`linyu` 与原词同形，或只是给官方机制、地图、赛季换个说法，释义里没有任何调侃语气的纯玩法词条。

### 剔除了什么

| 类别 | 条目 |
| --- | --- |
| 阵容与战术位（linyu 同形或纯换名） | 平衡队、核心输出→终端、单独防守→单防、送死精灵→炮灰、天气队、肉盾→大肉、拉条 |
| 官方机制/系统名 | 进化→首领化、猝死→猝亖、稀有度→出率、污染精灵、精灵球→咕噜球、亲密度、抽卡式捕捉→球数、吸能、绝版→销声匿迹 |
| 属性克制（两条重复） | 被克制→三倍弱电、三倍克制→三倍弱 |
| 地图 / 赛季 / 赛制 | 魔法学院、生态园、龙之秘境、占星台、圣龙宝藏、月涌狂想、星陨对局、星光对决、系别排位赛、皇家研究所 |

**留下了什么**：摔炮（一次性精灵）、就业/失业（上场）、处理（对付）、公式得不行（固定套路）、回宫/二进宫（回归）、钮祜禄（黑化）、低人一等厚、三倍弱电的自嘲用法、女子句式（雪天女子/冰队女子/火队女子/毒队女子）、赔钱草队、受队、大阴、严父、轮椅、花瓶、无人在意、辛者库宫女 —— 这些都有调侃语气，属于淋语而不是游戏说明书。

被剔除的只是**词库条目**，人物传与词卡不动：`进化` 从翻译词库消失，但精灵本人的介绍仍在人物传里。
