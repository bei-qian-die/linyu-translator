## 八、工程侧的重要改动（小程序 2MB 上限）

加完这轮数据后小程序主包从 1.90MB 涨到 **2.44MB**，超过微信 2MB 硬限制。三次尝试后落地的是「列式编码」：

1. `src/core/lore.js` 新增 `unpack()`：能识别 `{__col:1, keys, rows}` 格式并还原成对象数组，主端的常规对象数组直接透传
2. `scripts/build-weapp-data.mjs`：`seed` 与 `lore-extraN.js` 在小程序端输出为列式编码（列名只写一次，值按数组排）
3. 小程序端 `lore.js` 裁掉整行注释与空行
4. `test/weapp.test.js` 与 `scripts/verify-weapp-parity.mjs`：一致性从「字节相等」改为「解码后深相等」

结果：**2.44MB → 1.90MB**，主包重新回到限制内。

顺带修掉一个真 bug：`SEARCH_URL()` 用 `slice(0, 30)` 截断文本再 `encodeURIComponent`，正好切在 emoji 代理对中间会抛 `URIError: URI malformed`。本轮新增了大量带 emoji 的词条（我🐍 / 我🔒 / 🐔婆）才把它暴露出来，已修。

## 十、已知限制

1. **名言只到 +406，其中完全「有梗」的比例不高**：瓦罗语料里与淋语强相关的去重句子远少于第五人格，多数名言是「有观点有情绪」的评论区原句。所有 406 条都能在 corpus 里逐字查到，但没有为了凑数编造。
2. **11 位职业选手无配图**：他们的视频封面全是 UP 主压的大字标题或拼贴梗图，按「宁缺毋滥」留空。
3. **跨游戏角色只收了 2 位**：只有「猎天使moan女」「珊瑚宫⭐海」两条在瓦罗语料里有确凿的淋语式提及，其余按纪律不挂瓦罗分区标签。
