### 多译法（核心诉求）

同一中文词只建一条主记录，多种译法全塞进 alias：

- **监管者** → 屠夫 / 屠 / 监管者（「屠」偏组合词，如屠皇）
- **调香师** → 调马师 / 调香师（降格谐音，贬损式玩梗）
- **红蝶** → 我蝶 / 蝶 / 红蝶（人称式爱称）
- **抽卡** → 玄学抽卡 / 抽卡（挑吉时才叫玄学）
- **秒倒** → 秒倒 / 入口即化（后者更刻薄，把人类说成食材）
- **掌掴** → 掌掴（反问式「不掌掴你吗」是专属用法）

## 九、与优化提示词既定指标的差距（如实记录）

提示词第 1 节给的硬指标是 词库 +300 / 句式 +40 / 词卡 +150 / 人物 +60 / 名言 +400。实际交付 +135 / +30 / +46 / +51 / +63。

原因：本轮坚持「每条 linyu、alias、example、名言都必须能在语料里逐字命中」。全量语料 288.9 万字里，与第五人格真正相关的去重语句只有 319 条，能过验真的名言上限就是 80 条左右。为了凑到 400 条只能编造，而 `attest` 闸门会把编的全部打回。按提示词第 10 节的说明，选择「以现有语料为准，保底交付已验真部分」。

要补齐缺口需要继续扩语料（B 站第五淋格系列视频逐条抓评论、贴吧第五人格吧楼中楼），不是靠写数据能解决的。
