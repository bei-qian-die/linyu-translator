## 二、12 类词条分区结构

`scripts/curated-linyu16.js` 按以下 12 类组织，每类都有独立的 `source` 与 `pop` 口径：

1. 分区与玩家称谓（洛克淋国 / 小洛克 / 老洛克）
2. 谐音精灵（20 条，来自今日头条完整清单）
3. 页游经典外号（11 条，搜狗问问 / 搜狐宠物外号榜）
4. 玩家黑话
5. 队伍与属性（平衡队 / 虫队 / 天气队）
6. 场景与版本（S1–S5 / 赛季传说 / 异色机制）
7. 自称变体池
8. 鼠化家族
9. 语气词与谐音
10. 圈层黑话与审美
11. 淋文化典故
12. 宫斗体位分

**pop 不手写**：全部由 `scripts/freq-slots13.js` 对 255.7 万字语料逐字计数得出（高 ≥100 / 中 ≥20 / 低 <20），结果落 `evidence/slot-freq16.json`。
