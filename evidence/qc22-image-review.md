## 修复方法（本轮流程，供后续复用）

1. **检索词升级**：一律「第五人格 + 人名 + 官方全名 + 图鉴」（如「第五人格 医生 艾米丽·黛儿 图鉴」），官方全名取自词库 `baike`/`alias` 字段；标题黑名单过滤其它游戏与二创关键词
2. **每人物 8 张候选**落 `evidence/qc22-cand2/`，3 人/屏高清拼图人工复核
3. **定点补抓**：第一轮选不出合格图的人物（愚人金、律师、大副、黄衣之主、古董商、喧嚣、空军、时空之影）换检索词重抓（`qc22-cand3`）
4. **UP 主按规则用 B 站头像**（view API `owner.face`，代表作 BV 反查）：一只叫艾文的海豚、松下丶Aoki、gulpppppp、懂法的txz
5. **淋化创作角色**（凤蝶）用对应 B 站视频封面（BV1D9bx6AELi）
6. 淋人金Daddy（愚人金的淋化形象）与愚人金共用同一张官方图
7. 落地 `scripts/apply-hero-images22.py`：竖图裁顶部正方、横图居中裁正方 → 256×256 PNG **原地覆盖** hero-XXX.png（img 引用不变）+ 重生成 240 宽 WebP 缩略图
