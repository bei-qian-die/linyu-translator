# 淋语翻译器 · 30 秒宣发片（浏览器版）

一条**可在浏览器里自动播放的 30 秒竖屏片**，播完用录屏软件录一遍就是成片。
不需要剪映基础，改文案改节奏都只需动几行字，随时重录。

---

## 一、先看一遍

双击打开 `linyu-promo-30s.html` → 页面中央出现标题 → **点一下屏幕** → 3-2-1 倒计时 → 自动播放 30 秒。

播放期间右上角控制面板会在 **3 秒无操作后自动淡出**（鼠标一动就回来），所以录屏时不会入镜。

## 二、快捷键

| 键 | 作用 | 用途 |
|---|---|---|
| `空格` | 播放 / 暂停 | 逐段检查 |
| `R` | 从头重播 | 重录 |
| `1`–`7` | 跳到第 N 段 | 只想重录某一段时用 |
| `M` | 静音开关 | 想后期另配 BGM |
| `G` | 显示 15% 安全区参考线 | 检查字幕有没有被平台 UI 压到 |
| `H` | 隐藏 / 显示控制面板 | **正式录屏前按一下** |

## 三、录制：两条路，按对清晰度的要求选

### 路线 A｜OBS「浏览器源」（推荐，能录出原生 1080×1920）

1. OBS → 来源 → `+` → **浏览器**
2. 勾选「本地文件」，选中 `linyu-promo-30s.html`
3. 宽度 `1080`、高度 `1920`、帧率 `60`
4. 画布分辨率也设 `1080 × 1920`
5. 录制 → 点一下预览区让页面拿到焦点 → 点击开始 → 录满 30 秒
6. 音频：OBS 默认能收到浏览器声音，先试录 5 秒确认有声音

> 关键点：浏览器源是**按 1080 宽重新渲染**的，不是把屏幕画面放大，所以文字是清晰的。

### 路线 B｜直接全屏录屏（快，但会略软）

屏幕装不下 1920 高的窗口，页面会自动等比缩到屏幕高度，你录到的大概是 **608×1080** 左右，之后要在剪映里放大到 1080×1920，UI 文字会有一点发虚。

- Windows：`Win + G` 或 `Win + Alt + R`
- 只框住画面区域，不要录到桌面和浏览器工具栏

## 四、想改点什么

打开 HTML，找到这几处：

| 想改 | 位置 | 说明 |
|---|---|---|
| 所有字幕文案 | `<div class="cap" id="cap2">…` 等 | 直接改中文，注意 `<span class="hl">` 是渐变高亮字 |
| 开场钩子台词 | `const HOOK_TEXT = '小仙女今天好看惹，\n美cry噜'` | `\n` 是手写断行，**英文词别跨行**，否则会被拆开 |
| 模拟输入的内容 | `const TYPE_TEXT = '你今天真好看，我好开心！'` | 改完注意别超出输入框宽度（约 13 个字） |
| 三个大数字 | `1178` / `794` / `207` 三处 `.big-num` | 换版本后数字变了记得同步 |
| 每段时长 | `const SCENES = [...]` 和 `const CUTS = [...]` | 单位毫秒，总长由 `DURATION = 30000` 控制 |
| BGM 速度 | `Audio.bpm = 128` | 建议 110–130 之间，改完卡点位置要跟着调 `CUTS` |

改完存盘，浏览器刷新即可，不用重新构建。

## 五、发布前必须核对的 6 条

- [ ] **别让真人脸入镜特写**：第 6 镜（人物传 207）已对原截图做了强虚化，只保留数据大字，这是有意的——正片不做人物特写、不写对真人的定性描述
- [ ] 字幕逐条对字：错别字在这类梗内容里最伤，尤其「惹 / 噜 / 豪嗨心」
- [ ] 全片看一遍：无黑帧、无跳帧、无音画不同步
- [ ] 封面：另做一张，别用视频截图；人物占 60% + 3–8 个大字 + 高对比
- [ ] 标题里不要出现「淋语」以外的真人名字做噱头
- [ ] 上传后**在手机上看一遍**：平台会二次压缩，电脑上看不出问题的对比度在手机上可能糊

## 七、这套东西的已知边界

1. **BGM 是实时合成的电子节拍**（底鼓 + hi-hat + 合成器），不是成品音乐——好处是零版权风险，坏处是不够好听。想要真 BGM 就按 `M` 静音，录完在剪映里贴一首平台曲库的歌，按 `1`–`7` 跳段对齐卡点即可。
2. **没有真机操作录屏**（手指点击、输入过程）。现版本是用高清截图 + 推拉/打字动效模拟的。想升级：用手机自带录屏把「输入→点翻译→出结果」完整录一遍，替换第 2、3 镜，真实感会明显提升。
3. 三个大数字（1178 / 794 / 207）取自当前版本，换版本后必须同步，否则是硬伤。
