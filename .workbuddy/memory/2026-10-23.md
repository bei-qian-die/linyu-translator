# 2026-10-23

## 淋语翻译器 · 微信小程序端代码审查（对照开发计划书 v1.0）

产出：`小程序端代码审查与优化报告.md`（工作区根目录）

### 关键结论（供后续迭代直接复用）
- **数据/算法一致性已通过**：`miniprogram/core/translator.js`、`tokenizer.js`、`data/lore.js` 与 `src/core` 逐字节一致；seed 535 词 / 146 句式，lore 422 词卡 / 462 名言 / 73 人物，与计划书规模吻合。
- **小程序总体积 467KB**（data 373KB / pages 63KB / utils 13KB / core 9KB），远低于 2MB 限额，无图片资源。
- **5 个严重问题（P0）**：
  1. 剪贴板属微信隐私接口，未在 mp 后台《用户隐私保护指引》声明 → iOS 复制/粘贴直接 fail（`setClipboardData: fail api scope is not declared`）；需补 `__usePrivacyCheck__`。
  2. 分享 path 携带 500 字原文（encodeURIComponent 后 ~4500 字符）超 1024 限制 → 需截到 ≤300 字节。
  3. UGC（翻译结果）可直接分享，无 msgSecCheck / 敏感词兜底，违反计划书第九节"内容兜底过滤"。
  4. `app.js` 顶层 require content → 启动期同步解析 373KB 数据；需拆 `content`（仅 seed 42KB）/ `lore`（按需 require）。
  5. 翻译主链路无 try/catch，抛错会导致 `loading` 永久 true（翻译按钮禁用）；`app.js` 无 onError。
- **主要性能项**：setData 下发含 `searchText` 的全对象；长列表 loadMore 全量替换；每次翻译全量同步读写 storage（1000 条时约 1MB 序列化）。
- **计划书要求但未落地的三项**：三端一致性回归脚本、翻译耗时埋点、隐私合规配置。

### 约定/注意
- 工程无构建链、无分包，`scripts/build-weapp-data.mjs` 生成 `miniprogram/data/*`，勿手改。
