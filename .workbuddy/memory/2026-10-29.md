## 淋语翻译器 30 秒宣发片（promo/）

产出一条可在浏览器里自动播放的 30 秒竖屏宣发片，用 OBS 浏览器源或系统录屏一遍即成片。

- 文件：`promo/linyu-promo-30s.html`（单文件，无外部依赖，素材在同级 `promo/assets/`）
- 素材：复用 `design/screens/` 的 7 张 UI 截图（真实像素 1170×2532，铺满 1080 宽清晰度够，无需重拍）
- 结构 7 镜：钩子(2.5s) → 输入(2.5s) → 结果推镜(6s) → 三连数据卡点(6.5s) → 四端(5.5s) → 隐私卖点卡(4s) → 尾板(3s)
- 音频：WebAudio 实时合成底鼓/hi-hat/合成器 + 打字/叮/嗖音效，128BPM，**零版权风险**；按 M 静音可后期换真 BGM
- 交互：点击起始门 → 3-2-1 倒计时 → 自动播放；空格/R/1-7/M/G/H 快捷键；控制面板 3 秒无操作自动淡出（防入镜）

### 关键决策
- S1 钩子台词**硬编码 `\n` 断行**（`小仙女今天好看惹，` / `美cry噜`），否则英文词会被拆成 "美cr / y噜"
- S4 人物传一镜对截图做 **26px 强虚化 + 深色蒙版**，只出数据大字：规避真人肖像与非自愿定性描述风险，有意为之
- S6 隐私镜**弃用 06-settings-sheet.png**，改纯文字卖点卡——放大后会把"开发者模式/密码"输入框推进画面，不适合宣发
- 字幕渐变字 `.hl` 必须 `text-shadow:none`，否则透明文字上的父级阴影会堆成暗块
- 桌面截图 `.win-card img` 用 `height:332px + object-fit:cover` 裁掉原图下半空白，否则像个空窗口

### 踩过的坑（下次直接复用）
1. `__seek` 调试跳转必须清掉**所有** scene 的 active 类，只把 activeScene 置 null 会导致多幕叠加
2. AudioContext 未初始化时音效函数会抛异常并中断 render，所有音效方法开头都要 `if (!this.ctx) return`
3. headless 校验收需在 `Emulation.setDeviceMetricsOverride` 后补 `dispatchEvent(new Event('resize'))`，否则舞台按错误视口缩放
4. 断言"元素可见"要等 **动画 delay + 时长** 之后（最长 1.26s），900ms 会误判

### 校验
- `promo/assert-timeline.cjs`：10 个时间点断言，全部单幕激活 + 元素齐全 → 全通过
- `promo/play-test.cjs`：真实播放路径（点击门→倒计时→rAF 主循环）→ 时间正常推进、场景切换正确、无运行时异常
- `promo/shoot-preview.cjs`：按 1080×1920 输出 9 张关键帧到 `promo/preview/`

## 桌面端「没有润色按钮」根因排查 + 修复（15:10）

她反馈桌面端看不到润色按钮（记得 10-28 做过）。三层原因，全部已修：

1. **旧包 1.27.0 早于润色代码**：`release/win-unpacked` 构建于 10-28 01:47，而 `src/renderer/index.html` 的润色 UI 写于 23:19（`src/core/llm-polish.js` 20:25）。润色 Phase 2 一直是**未提交的工作区改动**（`git log -S polishOn` 无记录），从没进过 exe。
2. **模型名写死**：`main.js makePolish()` 默认 `qwen3:8b`，本机 Ollama 实际是 `qwen3:8b-fast` → `/api/chat` 404 → `polish` 静默返回草稿。即使 UI 有了也永远「没反应」。
3. **超时 + 脏输出**：客户端超时 30s，实测短句 10s、冷加载/长草稿 25~40s（qwen3:8b 首次 37s，且比 -fast 慢很多，疑与两模型来回换显存有关）→ 掐断回退；另外模型会把「原文：/润色后：」骨架复述回来，护栏照样放行，会污染结果栏。

改动：
- `llm-polish.js`：新增 `pickModel`（显式偏好 > 同 base 名优先 fast 变体 > qwen3 8b > 第一个）、`listOllamaModels`（/api/tags，4s 超时）、`cleanPolishOutput`（剥「润色后：」标签/引号/复述行）；超时 30s→90s
- `main.js`：`makePolish` 自动探测模型（60s 缓存），无可用模型时 throw，让前端能显示「润色没生效：…」
- `index.html` + `app.js`：结果面板加「润色 ♥」按钮（`polishNow`，不依赖开关），失败原因走 toast；tip 行补说明
- `eslint.config.js`：补 `AbortController` / `fetch` 全局（原文件 5 处 no-undef）
- 重新 `npm run dist` → `release/淋语翻译器 1.30.0.exe`（portable，133MB）+ `Setup 1.30.0.exe`，asar 已校验含 polishNow / pickModel / 90000 / cleanPolishOutput

遗留：`www/` `www-web/` 仍是旧构建，Web 端的润色按钮/清洗逻辑要 `npm run web:build` 才同步；小程序端 `cloudfunctions/polish` 未动。
