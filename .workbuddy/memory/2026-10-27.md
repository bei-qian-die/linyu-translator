## v1.26.0 收尾：132 张新图「浏览器端静默不生效」事故修复 + 线上部署（18:27~19:20）

### 根因（本次最有价值的发现，务必记住这个模式）

第 23 轮新增 `src/core/lore-extra23.js`，lore.js 里写了
`const extra23 = unpack(... window.LORE_EXTRA23 ...)`，但 **`src/renderer/index.html`
忘了登记 `<script src="core/lore-extra23.js">`**。

- 浏览器端走 `window` 分支 → `window.LORE_EXTRA23` 为 undefined
  → `unpack(undefined)` 返回空表 → `extra23.heroMerge`（132 条换图映射 + 1 条清空）
  **一条都没生效**；
- Node 端走 `require` 分支正常加载 → **串图闸门、单测、attest 全绿**，把问题完整漏过去；
- 结果：132 张新图躺在磁盘上，桌面端/网页端/手机端配图全是旧的，线上还停在 1.24.0。

**教训：多分支加载（require / window）的模块，「文件在」≠「数据在」。**
只校验「文件是否存在」的闸门查不出这类问题，必须校验「引用 ↔ 登记 ↔ 实存」三方差集。
