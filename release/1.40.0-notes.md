## 一个必须记下来的坑

抖音 19 位 id 直接 `JSON.parse` 会被双精度截断：

```
真实  7698968768599001897
解析后 7698968768599002000   // 末尾全变 0
```

第一轮采集 132 个候选音乐全部核验失败（页面打不开），排查才发现 id 是假的。
修复方式：用 Node 22 `JSON.parse` reviver 的第三个参数 `context.source` 取原始字面量，遇到 ≥16 位整数直接返回原文字符串。

```js
const reviveBigId = (k, v, ctx) =>
  typeof v === 'number' && ctx && typeof ctx.source === 'string' && /^\d{16,}$/.test(ctx.source)
    ? ctx.source
    : v;
```
