# 1.33.0 — 音乐板块扩到双平台（抖音 + 哔哩哔哩）

> 一句话：上一版只收抖音的「野花香 × Gulp」，这一版把 B 站那条同人线也接进来，
> 音源从 21 条涨到 **48 条**（抖音 37 / B 站 11），二创样例 25 → **88 条**，
> 界面多了平台徽章与平台筛选，门禁从「只认抖音链接」改成**按 source 分平台校验**。

## 为什么加

1.32.0 上线后翻了一圈数据：野花香在 B 站是另一套生态——不是「DJ 加速广场舞」，而是
**星穹金曲 / 原神金曲 / jiafei remix / 梗科普 / penbeat / 广场舞教学**；
Gulp 在 B 站则长成了**音效考据 + 发声教学 + 纯享版 + 阴乐争霸赛**。
两平台的梗是同源的，用法完全不同。只收抖音，等于只写了一半。

## 两平台的字段差异（这一版最容易被忽略的改造）

B 站**没有**抖音那种独立音乐页，所以条目的落点就是「引用该音源的作品页」：

| 字段 | 抖音 | 哔哩哔哩 |
| --- | --- | --- |
| `music_url` | `https://www.douyin.com/music/<id>` | `https://www.bilibili.com/video/<BV>` |
| `music_id` | 音乐 id（必填） | **`null`**（B 站无独立音乐 id） |
| `platform_id` | `null` | **BV 号（必填）** |
| `usage_count` | 音乐页「xx 人在用」 | 该作品播放量（界面上写「播放」而不是「人在用」） |
| 示例 `aweme_id` | 19 位数字 id | BV 号 |
| 示例 `play_count` | `null`（网页端不公开） | 有值（B 站公开播放量） |

界面据此分成两套措辞：抖音「打开音乐页 / 人在用」，B 站「打开原作品页 / 播放」；
平台徽章用抖音粉 `#fe2c55` 与 B 站蓝 `#00aeec`。

## 采集口径

### 抖音（增量）

站内搜索页这次**没能用**：`/search/` 直接返回「验证码中间页」（点击两个形状相同的物体），
登录态也一样。所以改走两条能打通的路径，都不绕过任何风控：

1. **音乐页扩展**：从既有的登录采集池（1738 条视频）里筛出标题命中 `野花香 / Jiafei / gulp` 系、
   且 `music_id` 不在 batch 1 基线里的音乐页候选 16 个，逐个打开 `music/<id>`，
   拦 `aweme/v1/web/music/detail` 拿 `music_info`（title / author / user_count / duration），
   拦 `aweme/v1/web/music/aweme` 拿「使用该音乐的作品」当样例池
2. **Gulp 反挖**：Gulp 在抖音没有独立音乐页（都是各号自己发的原声），
   于是按文案命中 `gulp/吞咽/吧唧` 的视频反查它们的 `music_id`，
   得到 175 个新原声音源，挑 15 个开页核验，取其中玩法最典型的进池

### 哔哩哔哩（新增）

- 搜索走 `api.bilibili.com/x/web-interface/search/type?search_type=video`（纯 HTTP，先访问首页拿 `buvid3`），
  17 组关键词 × 3 页，入池 **664 条**
- 相关性分组：野花香系 170 / Gulp 系 95 / 双音源 34 / 无关 365
- 合规 + 玩法打分（`梗/抽象/鬼畜/音效/教学/remix/缝合/阴乐` 加分，`黄/湿/裸/床/擦边/大尺度…` 直接剔除）
  后剩 92 条进入人工挑选

### 合规剔除

- B 站：CupcakKe 原曲 MV、`膏潮/糕超`类谐音、`猎奇/sm` 标签、擦边文案一律不收；
  只留梗解析、音效盘点、发声教学、纯享版、remix 缝合、广场舞教学这类平台判定合规的用法
- 抖音：剔掉带货挂车、纯搬运、擦边文案（含 `#pussy` 等 tag）与来源不明的水印作品

## 门禁改造（隐藏的大工作量）

原来 `build-music.mjs` 与 `test/music.test.js` 里的正则**只认抖音**，直接塞 B 站数据会当场失败。这一版：

- `scripts/build-music.mjs`
  - 双平台链接白名单：抖音 `music/<数字>` / `video/<19 位>`，B 站 `video/<BV 号>`
  - `music_id` 必填规则按平台放行：B 站必须为 `null` 且 `platform_id` 必填
  - 去重分池：抖音按 `music_id`、B 站按 `platform_id`，示例 id 全局唯一
  - `normalize()` 透传 `source / platform / platformId`，界面直接拿来用
  - `examples[].music_used === name` 这条老门禁保留
- `test/music.test.js`：26 → **38 条断言**，新增「两平台都有条目」「平台计数一致」「B 站 `music_id` 必须为 null」
  「示例 id 跨平台唯一」「同作者跨平台 ≤2」「平台筛选 / 平台+分组叠加」「平台名可搜」等
