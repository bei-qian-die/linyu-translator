# 淋语翻译器 1.36.0 · 跳页

> 想翻到第 10 页？敲个 10 就行 —— 四个分页列表的顶部和底部各加了跳页框，键盘直接敲数字也能跳。

## 一句话

词库 / 句式 / 词卡 / 名言**每一页都能直接跳**：顶部工具条、底部翻页条各一个「跳至第 N 页」输入框，回车即落页；不点输入框、直接敲数字同样生效。四端（桌面 / Web / 安卓 / 小程序）一起更新。

## 桌面 · Web · 安卓（同一份渲染层）

- **两个跳页框**：搜索框下方一个、底部翻页条一个。两处草稿分开存 —— 在顶部输入 12，底部不会跟着显示 12。
- **回车即跳**：输入框里敲完页码按回车，或点右侧「跳转」；跳完两个框同步显示落点，页况实时可见。
- **裸敲数字也能跳**：焦点不在任何输入框时，直接敲「1」「0」，右下角浮出「跳到第 10 页 · 回车确认 · Esc 取消」，回车落页、Esc 取消、2.2 秒无输入自动消失。输入框 / 文本域聚焦时数字键照常输入，不会被抢。
- **页码容错**：全角数字、「第10页」这类夹带文字都能解析；超出总页数自动夹到末页、小于 1 夹回首页；实在解析不出就留在原页并清空输入框，不会翻出空白页。
- **窄屏与触屏**：<568px 底部翻页条自动折行；触屏端输入框放大到 74px、隐藏「敲数字」提示（手机没有物理键盘）。

## 微信小程序

- 词库 / 句式（主包）与词卡 / 名言 / 人物（`pkg-hero` 分包）从「加载更多」累积列表改成**整页替换分页**：顶部一个跳页框、底部「上一页 / 第 N / M 页 / 下一页 + 跳页框」，每页仍 30 条。
- 顺带修掉一个隐性性能坑：累积模式下翻到第 100 页，视图层要背 3000 个节点；整页替换后数据量恒定 30 条，跳页只是一次 `slice`。
- 换 tab / 搜索 / 换筛选一律回到第 1 页，不会出现「内容变了页码没变」的错位。
