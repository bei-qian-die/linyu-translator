# 淋语翻译器 1.38.0 · 音乐板块扩展

> 音源从 62 条扩到 150 条：新增网易云 / QQ 音乐官方音源页，构建脚本改成平台注册表驱动，四端补齐收藏、最近浏览、排序、每日一条与分享。

## 一句话

音乐板块从「能翻的静态音源库」升级为「能用的音乐板块」：**音源 62 → 150 条（新增 88 条），二创示例 114 → 225 条（新增 111 条）**，四端（桌面 / Web / 安卓 / 小程序）同步。

## 轨道 B：数据层解耦

- `scripts/music-platforms.js` 建立平台注册表：`{key, label, shortLabel, musicUrlRe, exampleUrlRe, idField, musicIdPolicy, usageUnit, usageLabel}`。
- `build-music.mjs` 的链接校验、id 必填性、id 与 URL 尾段一致性、平台内唯一性、平台筛选器全部从注册表推导；新增平台只加一条配置。
- `GROUPS` 动态生成：tag 自动成组，`TAG_META` 提供稳定 key / 显示名 / 排序，组描述按条目数与高频玩法自动统计。
- 数据集 schema 升级：`batch: 4`、`platforms: ["douyin","bilibili","netease","qqmusic"]`，存量 62 条只补 `source`，其余字段未动。

## 轨道 C：用户态功能

- **我的收藏**：卡片心形按钮，四端同名 API（`getMusicFavs` / `toggleMusicFav`）。
- **最近浏览**：点开链接或查看详情即记录，保留最近 50 条，重复点开回到最前。
- **排序**：默认（数据集顺序）/ 热度 / 最近采集；热度按平台内最大值归一化，抖音「人在用」不与播放量、评论数混算，界面标明口径。
- **每日一条 / 随机一条**：每日一条用「本地日期 + slug」确定性哈希，同日稳定；两端一键跳到条目并复制链接。
- **分享**：小程序 `onShareAppMessage` 带音源名 / 作者 / 梗标签；桌面 / 安卓 / Web 复制链接 + 推荐语。
- **空态**：收藏为空、最近浏览为空均有明确文案。

### 存储落点

| 端 | 收藏 | 最近浏览 |
|---|---|---|
| 桌面 / 安卓 | SQLite `music_favs` | SQLite `music_seen`（限 50） |
| Web | localStorage `linyu.music.favs` | localStorage `linyu.music.seen` |
| 小程序 | `wx.setStorageSync`（`services/musicFav.js`） | 同左 |

静态音源不进用户库：150 条音源只走 `src/core/music.js`，不进 SQLite、不进导出备份、不进云同步。

## 已知限制

- QQ 音乐公开接口不返回播放量，本轮 `usage_count` 一律 null，不估算。
- 抖音剩余采集池没有符合口径的梗音源，本轮增量 0；后续需换关键词重新登录采集。
- 官方音源条目的示例来自同梗 B 站二创，`music_used` 按数据集约定写音源名，不宣称同一个录音版本。
- 桌面 exe 超过 100MB，Gitee 单文件上限 100MB，桌面版走 GitHub 下载。
